ComfyUI API (txt2img graph, API format):
```
{"4":{"class_type":"CheckpointLoaderSimple","inputs":{"ckpt_name":"sd_xl_base_1.0.safetensors"}},
 "6":{"class_type":"CLIPTextEncode","inputs":{"text":POS,"clip":["4",1]}},
 "7":{"class_type":"CLIPTextEncode","inputs":{"text":NEG,"clip":["4",1]}},
 "5":{"class_type":"EmptyLatentImage","inputs":{"width":W,"height":H,"batch_size":1}},
 "3":{"class_type":"KSampler","inputs":{"seed":SEED,"steps":32,"cfg":7.0,"sampler_name":"dpmpp_2m","scheduler":"karras","denoise":1.0,
      "model":["4",0],"positive":["6",0],"negative":["7",0],"latent_image":["5",0]}},
 "8":{"class_type":"VAEDecode","inputs":{"samples":["3",0],"vae":["4",2]}},
 "9":{"class_type":"SaveImage","inputs":{"filename_prefix":PREFIX,"images":["8",0]}}}
```
- POST /prompt with body `{"prompt": graph, "client_id": "<uuid4>"}` returns `{"prompt_id": "..."}`.

- GET /view?filename=F&subfolder=S&type=output returns the PNG bytes.
The sampler, scheduler, steps and cfg match the locked assets/sprites/comfyui-workflow.json.

Existing PROVENANCE.json shape: `{ schema_version:1, checkpoint_license:{...}, assets:[ {filename, path, actor, ...} ] }`. The player-atlas.png entry must be preserved byte-for-byte except for intentional edits.

1. **tools/art/finish_sprite.py** `--in RAW --out FRAME.png --size 128|256 [--silhouette OUT.png]`:

   - Zero alpha below 16.
   - Crop to the alpha bbox, then keep only the largest connected alpha component plus components larger than 2% of it. This drops speckles; use numpy + a simple flood-fill/label, or PIL-only if simpler.
   - Fit into size×size keeping aspect with a 4px margin, **bottom-center aligned** (feet at the bottom edge − 4px), LANCZOS, transparent background.
   - Save RGBA PNG. The optional silhouette is a black-on-white of the alpha, for the readability self-review.
   - Print the bbox and fill ratio.
2. **tools/art/finish_biome.py** `--in RAW --out BG.png`: cover-scale 1344x768 to 1280x731 with LANCZOS, center-crop to exactly 1280x720, convert to RGB, save with PNG optimize=True. Print the file size.
3. **tools/art/phase2_variant.py** `--in FRAME.png --out FRAME_P2.png --mode ember|divine`. It preserves the RGBA canvas size and alpha footprint, and the glow may extend into the transparent margin.

   - divine (Yama only, D-15a): NO hue shift, NO darkening beyond 5%, contrast +8%, and a two-layer glow behind (inner #9fb8ff blur 5px at 0.8, outer #ffd34d blur 12px at 0.45). It reads as "divine wrath", not demonic.
