The categories cover weapon, biome, boss and meta (STEAM-02). There are 4 boss-encounter items. The three Warden bosses are framed per biome. Rakshasas/asuras may be "overcome". Yama is only ever "the Trial".

reduceRun(run, event, payload). It is pure: it returns a new object and never mutates its input.
- 'run_start' → `{ weapon: payload.weapon, gods: [], duos: [], biome: null, vaitaraniClean: false, reachedTrialClean: false }`
- 'biome_enter' → biome = payload.biomeId. When it is 'vaitarani', vaitaraniClean = true.
- 'player_hit' → when biome === 'vaitarani' and !reachedTrialClean, vaitaraniClean = false.
- 'boss_enter' with bossId 'yama' → reachedTrialClean = vaitaraniClean.
- 'boon_taken' → add def.god, plus every def.gods entry for duos, to gods (deduped). Duos also add def.id to duos.
- any event when run is null, other than 'run_start' → returns null.
- unknown events → run unchanged.

recordLifetime(m, event, payload):
- 'boss_passed' → push the bossId into m.bossesPassed, deduped.
- 'boon_taken' with def.duo → push def.id into m.duosUnlocked, deduped.
- 'run_won' → m.weaponWins[weapon] = (m.weaponWins[weapon]|0) + 1.

evaluate(m, r, D, unlocked) → the ids, in DATA.ACHIEVEMENTS order, whose predicate is true and that are not in `unlocked`. A predicate that throws counts as false.

META.migrate(raw) is pure and returns a normalized save object:
- Missing `lifetimePunya` → raw.punya + Σ over DATA.META of cost[0..rank-1] + Σ DATA.WEAPONS[w].unlock for each unlocked w.
- Missing `bossesPassed` → DATA.BIOMES.slice(0, bestBiome).map(b => b.boss), plus 'yama' if wins > 0.
- Missing or invalid `duosUnlocked` → [].
- Missing or invalid `weaponWins` → {}.
- Missing or invalid `achievements` → {}.
- `saveVersion` = 2.
- Existing valid values are preserved.
- Non-array or non-object garbage → defaults.

META.earnPunya(n): punya += n, lifetimePunya += n, then save(), then ACH.notify('meta').
