## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The plan's prompt text contradicts its own LINT acceptance**
- **Found during:** Task 1
- **Issue:** The verbatim subject endings ("no halo, no crown", "no forehead marks") and the style clause ("no scenery, no text") match the negation LINT that the plan requires to be absent.
- **Fix:** Rewrote them as positive anchors with the same intent: "a bare head with only the plain grey backdrop directly behind it", "a smooth bare forehead", "background that fills the rest of the image". There are 0 LINT lines on all 12 subjects.
- **Commit:** bd7458d

**2. [Rule 3 - Blocking] `seed_for` evaluates `entry["base_seed"]` eagerly**
- **Issue:** A dry-run of the new subjects raised KeyError.
- **Fix:** Added `base_seed` (= `flux_base_seed`) to the 12 entries. This is a data-only change, so legacy behaviour is untouched.
- **Commit:** bd7458d

**3. [Rule 2 - Correctness] src_only guard in rebuild_atlases.py**
- **Issue:** The new rows have no recovered SDXL source. A full `--build`, `--legacy-check` or `--matte-preview` would have crashed on them.
- **Fix:** `src_only` rows are skipped unless `--src KEY=...` is given.
- **Commit:** bd7458d

**4. [Rule 2 - Correctness] record_provenance dropped QA-03 fields for enemies**
- **Issue:** `--iconography` and `--cultural-check` were ignored for `kind: enemy`, so the QA-03 flags the plan requires would have been lost.
- **Fix:** Enemy entries now record `cultural_review`, `iconography_notes` and `cultural_check`, and boss entries record `cultural_check`. Pishacha's entry was re-recorded.
- **Commits:** 35537c3, 7b5ee93

**5. [Rule 3 - Blocking] scale_preview had no old frame for new actors**
- **Fix:** New actors are previewed beside a committed same-biome reference actor (preta, bhuta, naga, vetala, archer, daitya, yatudhana, tataka, ahiravana, kumbhakarna, yama), each at its own r.
- **Commit:** 1cbd909

**6. [Plan fallback applied] Mini-bosses at 384 px instead of 512**
- **Reason:** The plan's GPU-budget rule. The projected total at 512 was about 25.4 MB against the 24 MB limit. The actual total is 19.94 MB.
- **Commit:** bd7458d

**7. [Rule 2 - Cultural guard] Maricha forehead mark removed with retouch_mark.py**
- **Issue:** The 3-attempt cap was exhausted, and every attempt painted a tilak-like mark.
- **Fix:**
  - Added a `--cool` mask mode for green/blue paint on golden skin; default behaviour is unchanged.
  - Retouched the least-bad attempt.
  - Shipped it FLAGGED, following the 05.7-02 precedent.
  - Recorded the step in `post_processing` and AI-DISCLOSURE.
- **Commit:** aa80267

**8. [Tuning] Outline width for mayavi**

**9. [Tooling] contact_sheet.py**
