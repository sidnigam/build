| SDXL failure mode (05.5-01, 0/6 in 42 attempts) | Flux outcome (05.5-04, 6/6) |
|---|---|
| Statue/pandal-idol renders | Not observed on any Flux attempt — every raw read as a living painted figure with open eyes (HX2 passed on every ship candidate) |
| Halos and frames around the figure | Durga's round-1 crown generated a halo-like radiant arch (the one recurrence of this failure mode); fixed with a positive-only tiara rewrite in round 2. No other god showed this pattern. |
| Wrong arm counts | Durga's round-0 raw had 6/8 arms (same family of failure); round 1 fixed the count with an explicit "four arms rise from each shoulder, eight arms total" anchor and it held through round 2 |

| A feminine-presenting Vayu | The Flux result reads as a clearly bearded, masculine, dignified mature man — this SDXL failure mode did not recur |
| Held props destroyed by the rembg cutout | Solved structurally by the `birefnet-general` matte (Task 3 bake-off) plus props pressed against the body in the prompt (D-30) — every shipped god's held prop (gada, flame, Vajra, staff, flute, trident/sword/mace) survived the finished cutout intact |
| (New, Flux-specific) Full-body framing instead of a waist-cropped bust | Caused by early mentions of lower-body garments (dhoti, sari) within CLIP-L's ~77-token attention window; fixed per-god by leading the prompt with an explicit bust-crop anchor clause |
| (New, Flux-specific) An upright "double-ended" Vajra read as a trident | Vertical/upright framing of a pronged object defaults to a trident silhouette regardless of "double-ended" phrasing; fixed by describing the Vajra held horizontally with prongs mirrored left/right |
| (New, Flux-specific) An anachronistic wristwatch from vague jewellery phrasing | "Light silver jewellery" under-specified; fixed with an explicit upper-arm armband + bare-wrists description |

**Net:** Flux did not reproduce the two most distinctive SDXL identity failures (human-faced Hanuman, feminine Vayu) at all, and the held-prop-loss problem was solved by the matte/composition combination rather than the checkpoint alone. Flux introduced its own narrower set of failure modes (full-body framing, trident-reading weapons, under-specified jewellery, a halo-reading crown) — all of which were positive-phrasing composition/wording problems, fixable within 1-2 targeted rewrite rounds per god rather than requiring more raw attempts.

## Decisions Made

- Adopted `birefnet-general` (no keyfill) as the god-portrait matte default (Task 3 CPU bake-off).

- Did not pursue the deferred 05.5-01 idea of compositing a separately-generated prop into a god's hand (D-31) — unnecessary, since the matte/composition fix recovered every held prop without it.
