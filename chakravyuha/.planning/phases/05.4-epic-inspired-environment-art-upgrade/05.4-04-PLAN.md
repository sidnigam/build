<objective>
Build the runtime environment renderer, `js/environment.js`, and wire it into the render pass. It turns a biome manifest plus the current room (`GAME.arena`, obstacles, hazards, doors) into Hades-style layered set dressing: a tiled floor, architecture, props, obstacle/hazard skins, and lights/atmosphere. It stays within the readability and performance guardrails.

Purpose: ENV-02..06 and ENV-09. This is the code half of the phase. It is built against the D-11 manifest contract so it can land before or in parallel with the art (05.4-02/03). With no manifest it degrades to a procedural/legacy-bg kit.
Output: js/environment.js, renderBackground/renderObstacles integration, script tag, appended smoke checks, and the env_shots.mjs screenshot driver.

**External dependency:** Phase 05.1 must be merged first (larger arenas + scrolling camera). Task 1 starts by reading what 05.1 actually built.
