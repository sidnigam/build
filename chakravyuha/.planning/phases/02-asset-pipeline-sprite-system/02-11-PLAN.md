<interfaces>
Pipeline built in 02-08. All Python is run with `~/ComfyUI/venv/bin/python`:
- `tools/art/gen_subject.py <key> --attempt N [--wait-only PROMPT_ID]` writes `assets/sprites/_gen/{kind}s/{key}/{key}_s{seed}.png` + `.gen.json`. The seed is base_seed + N. Use a Bash timeout of 600000, and if it times out, resume with --wait-only.
- `tools/art/finish_sprite.py --in RAW --out FRAME.png --size 128|256 [--silhouette OUT.png]` does rembg → despeckle → trim → bottom-center fit.
- `tools/art/phase2_variant.py --in FRAME.png --out FRAME_P2.png --mode ember|divine`
- `tools/art/record_provenance.py --filename --path --actor --kind --sidecar --rejected-seeds --post --self-review --animations --raw` upserts into PROVENANCE.json.
- `node tools/pack-atlas.js <inputDir> <textureName> <outDir>` packs every *.png in inputDir. Frames are named `{key}_{anim}_{n}.png`, and it injects `animations` into the JSON (e.g. {idle:[...], phase2:[...]}).
- `node tools/check-provenance.js` checks that every *-atlas.png / *-bg.png has a complete entry.

Runtime facts that shape the art:
- The facing flip assumes source art faces RIGHT (SPRITES.CFG.DEFAULT_FACING = +1, a single global). Art that faces left must be mirrored at finish time. Symmetric front-facing art is fine as is.
- On-screen height = r × 4 (bosses the same, BOSS_HEIGHT_PER_R). Enemy r values from js/data.js: preta 11, rakshasa 15, archer 13, naga 14, vetala 13, bhuta 21, daitya 19, yatudhana 14. Boss r values: tataka 34, ahiravana 30, kumbhakarna 46, yama 36. So enemies render about 44–84px tall and bosses about 120–184px. Chunky, bold silhouettes matter more than detail.
- Width is clamped to r × MAX_WIDTH_PER_R (5) by 02-07, so wide poses (a coiled naga, a hulking bhuta) are scaled down rather than overflowing.

Self-review checklist (tools/art/README.md, D-14a):
- (a) correct subject
- (b) full body in frame
- (c) exactly one character
- (d) no text or watermark
- (e) no extra limbs or heads
- (f) silhouette readable (inspect the --silhouette PNG)
- (g) clean cutout, no halo
- (h) cultural guard respected (D-15a):
  - Yama is dignified: no fangs, horns, skull face or demonic features.
  - The naga is a serpent-folk warrior: no halo, no multi-hood divine iconography.
  - No enemy looks like a deity: no halo, no divine iconography.
Up to 4 retries (5 attempts) per character. If all 5 fail, keep the least-bad attempt and begin self_review with "FLAGGED:".
