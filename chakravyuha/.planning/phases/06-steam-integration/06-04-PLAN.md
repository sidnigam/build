   - Byte quota 1048576, files 10.
   - Enable **Auto-Cloud**.

   - Root override for macOS → `MacAppSupport`, same subdirectory.
   - Publish.

   - Create depots for Windows and macOS.
   - Build with `npm run dist:win` (on Windows or CI) and `npm run dist:mac`. Unsigned is fine for private testing.
   - Upload with the ContentBuilder GUI or steamcmd.
   - Set the build live on a password-protected **beta** branch, not default.
6. Install Steam on two machines (ideally Windows + Mac), opt into the beta and install the game.
