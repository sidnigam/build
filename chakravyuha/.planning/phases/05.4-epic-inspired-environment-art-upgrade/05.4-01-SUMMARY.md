## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `gen_subject.py`'s `--ckpt-profile` only worked for env keys, but the orchestrator amendment required A/B-ing two existing god subjects (legacy kind) on both checkpoints**
- **Found during:** Task 3, preparing the god A/B generation
- **Issue:** `resolve_checkpoint()` only consulted `--ckpt-profile` when `kind == "env"`; legacy subjects (god/boss/enemy/biome) always used their own `checkpoint`/`checkpoint_label` config, ignoring any override. The output-path builder also didn't add a profile suffix for legacy keys, so two checkpoint runs of the same god+seed would have overwritten each other.
- **Fix:** `resolve_checkpoint()` now uses the checkpoints catalog whenever `ckpt_profile_override` is truthy, regardless of kind; the legacy output-path branch in `run_one()`/`output_path_for()` now appends the same `_{profile}` suffix env keys already used. Legacy behavior with no `--ckpt-profile` given is unchanged (verified via dry-run diff against `naraka`).
- **Files modified:** `tools/art/gen_subject.py`
- **Verification:** dry-run for `naraka` unchanged; dry-run for `vayu --ckpt-profile sdxl_base --attempt 1` correctly resolved seed 71301 + sdxl_base; both god subjects generated successfully on both checkpoints without filename collisions; `node test/smoke.js` and `node tools/check-provenance.js` green throughout
- **Committed in:** `32d3b06` (Task 3 commit)

**2. [Rule 1 - Bug] `grade_tile`'s HSV-desaturate step, run before the final value scale, raised luma_mean instead of lowering it**
- **Found during:** Task 2, `finish_env.py --self-test`
- **Issue:** Desaturating a vivid synthetic tile toward grey raises its luma (the minimum RGB channel rises toward the max/"V" channel at fixed value), so doing the value-scale pass *before* the saturation pass let the saturation step push luma_mean back above the limit after the value step had already brought it under.
- **Fix:** Reordered to contrast-compress → desaturate → value-scale-last, so the final pass always lands luma_mean under the limit regardless of what desaturation did to it.
- **Files modified:** `tools/art/finish_env.py`
- **Verification:** `--self-test` failed before the fix (`FAIL tile stats + grade`, luma_mean 0.47 -> 0.60 post-grade) and passed after (all 5 behaviors PASS)
- **Committed in:** `0255f6e` (Task 2 commit, self-test caught this before any commit was made)
