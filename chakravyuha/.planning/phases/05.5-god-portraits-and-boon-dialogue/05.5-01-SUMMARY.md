## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `gen_subject.py` `main()` referenced an unbound `entry` variable**
- **Found during:** Task 2, first Krishna generation attempt (before any image was produced)
- **Issue:** `build_prompt()` computed `entry` locally but `main()` never bound it before reading `entry.get("checkpoint")`/`("checkpoint_label")`, so every subject (not just gods) would crash with `UnboundLocalError`
- **Fix:** Bind `entry = subjects[args.key]` in `main()` immediately after calling `build_prompt()`
- **Files modified:** `tools/art/gen_subject.py`
- **Verification:** `py_compile`, the offline `build_prompt` sanity checks, `check-provenance.js`, and `test/smoke.js` all green; Krishna generation then queued and completed successfully
- **Committed in:** `4f4a205`

**2. [Rule 3 - Blocking] `finish_portrait.py` did not create its own output directories**
- **Found during:** Task 2, first Krishna finish step (`assets/sprites/gods/` did not exist yet)
- **Issue:** The script errored with `No such file or directory` instead of creating the parent directory for `--out`/`--silhouette`, unlike the rest of the pipeline's finishing tools
- **Fix:** `os.makedirs(..., exist_ok=True)` for both output paths before processing
- **Files modified:** `tools/art/finish_portrait.py`
- **Verification:** `py_compile`; re-ran the Krishna finish step successfully afterward
- **Committed in:** `2e3626d` (bundled with the Krishna portrait commit, since it was found and fixed in the same step)
