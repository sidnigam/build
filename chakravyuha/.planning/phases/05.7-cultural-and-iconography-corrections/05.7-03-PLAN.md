"fg" means `alpha>128` for RGBA inputs, and "colour distance from bg > tol" for RGB inputs. `--bg auto` means the per-channel median of the 8-px border ring of the image.

**tools/art/prop_overlay.py.** It uses argparse subcommands. Coordinates are always in the input image's pixel space. The polygon format is `"x,y x,y x,y ..."` (space-separated pairs).

1. `grid --in IMG --box x0,y0,x1,y1 [--step 20] [--scale 2] --out PNG`
   - Crop the box, flatten RGBA over #767676, and upscale ×scale with LANCZOS.
   - Draw 1-px gridlines every `step` SOURCE pixels: cyan, with every 5th line in yellow.
   - Label every second line with its SOURCE coordinate, in a 10 px font, on both the top and the left edges.
   - Purpose: the executor reads exact coordinates off it.
2. `mask --in IMG --out MASK.png [--poly P]... [--rect x0,y0,x1,y1]... [--keep-skin x0,y0,x1,y1]... [--fg-only] [--bg auto|#rrggbb] [--tol 40] [--dilate 3] [--preview PNG]`
   - mask = union of the polys and rects (filled, 255).
   - If `--fg-only`, AND it with fg.
   - Dilate by `--dilate` px (elliptical kernel).
   - THEN, for each keep-skin box, zero the mask where the pixel is skin inside that box. Skin rule (HSV, H in degrees): (H ≤ 35 or H ≥ 345) and 0.20 ≤ S ≤ 0.80 and 0.20 ≤ V ≤ 0.95.
   - Preview: the image flattened over #767676 with the mask tinted red at 50%, plus a 1-px yellow contour of the mask.
   - Print `{area_px, frac, bbox}`.
3. `fill --in IMG --mask MASK --mode bg|telea [--bg auto|#hex] [--radius 9] --out IMG`
   - `bg`: set the masked pixels to the bg colour, then run `cv2.inpaint` TELEA (radius 3) on a 3-px ring straddling the mask edge, so the junctions blend.
   - `telea`: `cv2.inpaint` TELEA with `--radius` over the mask.
   - The RGB channels only are changed; alpha is preserved.
4. `fgmask --in IMG --box x0,y0,x1,y1 [--bg auto] [--tol 40] --out MASK [--preview PNG]`: fg inside the box, 0 outside.
5. `handmask --in IMG --box x0,y0,x1,y1 [--poly P] --out MASK [--preview PNG]`
   - Skin rule (as in `mask`) inside the box.
   - Morph close 3 px, then keep the largest connected component.
   - If `--poly` is given, use the polygon (filled) instead of the skin rule.
6. `realpha --orig RGBA --rgb RGB --mask MASK [--grow 6] [--feather 3] [--matte birefnet-general] [--bottom-feather 0.12] --out RGBA`
   - Use the SAME soft mask that guided_inpaint uses. M = (mask dilated by `--grow`) Gaussian-blurred with sigma `--feather`, as a float in 0..1. G_hard = mask dilated by grow + 3·feather (15 px by default). M is forced to 0 outside G_hard.
   - Output RGB = orig_RGB·(1−M) + rgb·M.
   - Output alpha = orig_alpha·(1−M) + A_new·M. A_new is the `rembg(rgb)` alpha (via `finish_portrait.get_session(matte)` + `rembg.remove`) × the bottom-feather ramp (`finish_portrait.bottom_feather(…, bottom_feather)` applied to an all-255 RGBA of the same size, alpha column read back).
   - Blending with the soft M means there is no hard seam ring at mask+grow. Pixels outside G_hard are byte-identical to orig.
7. `vajra --size W,H --center x,y --length L [--angle 0] [--palette-from IMG --palette-mask MASK] [--palette-gold 1] [--outline 2] [--glow 0] --out LAYER.png [--standalone PNG] [--metrics JSON]`
   - Draws a classic double-ended vajra in a local frame and renders at 4× supersampling.
   - Local frame: u along the axis, from −L/2 to +L/2; v perpendicular, with v>0 = up. Every value below is a fraction of L, and every element is mirrored at u → −u:
     - BALL: circle at (0,0), r 0.070, plus 3 thin ink rib arcs.
     - RING1: rounded rect centred at u=0.090, half-length 0.016, half-height 0.080.
     - LOTUS: ellipse centred at u=0.150, a=0.055, b=0.072, plus 3 ink petal arcs.
     - RING2: rounded rect centred at u=0.215, half-length 0.014, half-height 0.062.
     - CENTRAL PRONG: tapered polygon from u=0.229 (half-width 0.020) to the tip (0.500, 0).
     - OUTER PRONGS, upper and lower (mirror v → −v): cubic Bézier P0 (0.229, ±0.050), P1 (0.300, ±0.150), P2 (0.420, ±0.120), P3 (0.497, ±0.004). Stroke width tapers 0.026 → 0.010 along t. Stroke by sampling 64 points and offsetting along normals into a closed polygon.
     - INNER PRONGS, upper and lower: Bézier P0 (0.229, ±0.028), P1 (0.290, ±0.085), P2 (0.400, ±0.070), P3 (0.470, ±0.006), width 0.018 → 0.008.
   - Draw order, back to front: outer prongs, inner prongs, central prong, RING2, LOTUS, RING1, BALL. Each shape is filled, then stroked with a 1-px ink line (ink = (46,26,6)).
   - Colour per pixel: vertical gradient over v ∈ [−0.121L, +0.121L], top light → mid → bottom shadow, piecewise linear.
