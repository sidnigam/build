# Phase 05.7.1 Plan 09: Vows of Tapas (Heat) Summary

**The game now has an opt-in Heat system called Vows of Tapas, modelled on Hades' Pact of Punishment. It has 12 vows worth up to 46 Heat and unlocks after the first full clear. Every vow is wired into gameplay. Each run freezes its vows into `GAME.heat`. Total Heat multiplies Punya by ×(1 + 0.05·Heat), and the first clear at a new best Heat per weapon pays a one-time bounty of 20 + 5·Heat. A run with no vows plays exactly as before; the seeded balance sim output is byte-identical to the pre-plan baseline.**

## HEAT API (as shipped; plan 10 builds the hub panel on this)

```js
DATA.HEAT = { unlockWins: 1, punyaPerHeat: 0.05, bountyBase: 20, bountyPerHeat: 5,
  vows: [{ id, name, ranks, heat: [perRank...], desc: r => string }, ...12] }

HEAT.vow(id)                 // -> vow def | undefined
HEAT.unlocked()              // META.wins >= DATA.HEAT.unlockWins
HEAT.rank(id, sel = META.heat)   // clamped [0, ranks]; unknown id -> 0
HEAT.setRank(id, r)          // clamp, 0 deletes, META.save(); unknown id ignored; returns stored rank
HEAT.total(sel = META.heat)  // sum of heat[0 .. rank-1]
HEAT.effects(sel = {})       // frozen { total, enemyDmg, enemyHp, budget, haste, eliteShareMul, eliteModBonus,
                             //   extraMoves, chainBonus, restMul, phaseAtBonus, healMul, noSarovar, projExtra,
                             //   projSpeed, shopMul, boonChoicesMinus, roomTimer, tokens }
HEAT.beginRun()              // GAME.heat = effects(unlocked ? META.heat : {}); GAME.heatTotal; GAME.heatSel (copy)
HEAT.punyaMul()              // 1 + 0.05 × GAME.heatTotal
HEAT.punya(n)                // Math.round(n × punyaMul())
HEAT.heal(n)                 // Math.round(n × GAME.heat.healMul) (neutral if GAME.heat absent)
HEAT.onVictory(weaponId)     // bounty if GAME.heatTotal > META.bestHeat[weaponId]; records best, adds to
                             //   META.punya + player.punyaRun, saves; else 0. Heat 0 never pays.
```

`META.heat` maps vow id to rank. `META.bestHeat` maps weapon id to the best Heat cleared with it. Both are validated as plain objects on load (anything else loads as `{}`), written by `save()` and reset by `wipe()`.

## Vow → hook map

| Vow (ranks, Heat) | Effect field | Hook |

| Pain (5, 1 each) | enemyDmg 1 + 0.2r | Enemy ctor, Boss ctor, MiniBoss ctor (applied after its `dmg = 14`) |

**1. [Rule 1 - Bug] Wardens rank 1 had nothing to lend for three champions**

- **Issue:** Subahu, Mahiravana and Maricha have no phase-2 move outside phase 1 other than the enrage opener. The planned "first non-opener phase-2 move" rule would give them no extra technique, so the vow ("know one more technique from the start") would do nothing.

- **Files modified:** js/entities.js
- **Commit:** f7e6f85

**2. [Rule 1 - Bug] Storms extra shots would stack on one line**
- **Found during:** Task 2
- **Issue:** `planPattern` 'player' with `spread: 0` aims every shot at the same angle, so +2 count would stack three shots on one line.
- **Fix:** When Storms adds shots to a zero-spread aimed pattern, it uses spread 0.12·(n − 1), giving ±0.12 rad steps. This is the same step as the archer fan.
- **Files modified:** js/combat.js
- **Commit:** f7e6f85

**3. [Rule 3 - Blocking] bossai suite asserted `GAME.heat === undefined` after startRun**

- **Fix:** The check now asserts that a no-vow run carries neutral hooks: chainBonus 0, restMul 1, extraMoves false.
- **Files modified:** test/combat/bossai.test.js
- **Commit:** f7e6f85

**4. [Rule 1 - Bug] HUD timer position**
