# Phase 05.2 Plan 03: Aim indicator, HUD glyphs, rumble Summary

**A pad player now sees a gold world-space aim arc + chevron circling Abhimanyu (with a diamond marker on any aim-assist-locked enemy) instead of a mouse crosshair, a DASH/ASTRA/SPECIAL glyph legend on the HUD that matches their controller family, and felt DualSense/DualShock rumble on hits, kills, damage, boss slams, boss phase changes, boss death and player death — all feature-detected, intensity-scaled, and silently no-op when unsupported, off, or when keyboard/mouse is the active device.**

## Accomplishments

- **Rumble engine (PAD-07):** `PAD.RUMBLE_PRESETS` (kill/hit/crit/hurt/heavy/test, each with a base
  duration/weak/strong magnitude and a priority tier) plus `PAD.VFX_RUMBLE` mapping VFX preset names
  to rumble presets (`hit`→hit, `crit`→crit, `death`→kill, `hurt`→hurt, `phase`/`bossDeath`→heavy).
  `rumblePreset(name, intensity)` scales and clamps magnitudes to `[0,1]`, returning `null` for an
  unknown preset or non-positive intensity. `rumbleShouldPlay(now, active, tier)` is the pure
  tier-priority + 50ms same-tier throttle gate: a weaker or equal-tier preset never interrupts one
  still playing, and same-tier repeats are throttled to >= 50ms apart, while a strictly higher tier
  always plays immediately. `_playOn(gp, eff)` feature-detects `gp.vibrationActuator.playEffect` and
  calls it with `{startDelay:0, duration, weakMagnitude, strongMagnitude}`, swallowing both thrown
  exceptions and rejected promises, never throwing. `rumble(name, opts)` is the single public gated
  entry point (`SETTINGS.rumble`, `INPUT.device === 'pad'` unless `opts.force`, a positive
  `rumbleIntensity`, and the tier/throttle gate) that a controller-test "Test rumble" button (Plan 04)
  can call directly with `{force:true}`.
- **VFX/shake/death hooks:** `PAD.installRumbleHooks()` idempotently wraps `VFX.emit` once (guarded
  by `VFX.emit._padRumble`) so every existing combat `VFX.emit('hit'/'crit'/'death'/'hurt'/'phase'/
  'bossDeath', ...)` call also fires the matching rumble preset — no edit to `js/vfx.js` or
  `js/entities.js`. Called unconditionally at the bottom of `js/gamepad.js` (VFX already loaded).
  A pure `rumbleEventFromFrame(prev, cur)` detector additionally catches a boss-slam (a `GAME.shake`
  jump of >= 10 while a boss is alive) and player death (`GAME.state` becoming `'dead'`), fed one
  `{shake, state, boss}` frame at a time from `poll()` right before the FOCUS menu gate — so it only
  runs, and only rumbles, while a pad is the active input device.
- **World-space aim indicator (PAD-06):** pure `GAME.aimIndicatorGeom(px, py, aim, r)` returns the
  gold arc radius/span (`r+30`, `aim ± 0.35` rad) and chevron tip/left/right points (`r+44+8` along
  `aim`, chevron wings at `r+44-4` and `±0.22` rad). `GAME.renderAimIndicator(ctx)` draws it — plus a
  gold diamond outline on `PAD.state.assistTarget` when aim-assist has locked a live enemy — only
  while `INPUT.device === 'pad'` and the player is alive and in a run or paused. Wired into
  `render()`'s world pass immediately after `renderEffects(ctx)`, inside the existing `CAMERA.begin()`/
  `CAMERA.end()` block, so the scrolling-camera transform applies automatically with no manual
  world<->screen conversion.
- **Crosshair swap + HUD glyphs (PAD-04/PAD-06):** `renderHUD`'s crosshair block now only draws while
  `INPUT.device !== 'pad'` (previously it projected the pad's world-space aim back to screen space and
  drew a crosshair there too — now pad players get only the world-space indicator). The old single
  `"SPECIAL [E / RMB]"` / `"SPECIAL [LT / X]"` text line is replaced with a `DASH` / `ASTRA` / `SPECIAL`
  legend, each a short text label plus `GLYPHS.drawTokens(ctx, x, by+52, GLYPHS.tokensFor(action), 12)`
  — so a DualSense player sees ○/△/L2·□ badges under the dash pips, cast lotuses and special bar,
  switching live with the active device/family, with a plain-text fallback when `GLYPHS` isn't loaded.

## Decisions Made

See `key-decisions` in frontmatter. Summary: `installRumbleHooks()` runs eagerly at gamepad.js load
time (VFX already loaded by then in both index.html and smoke.js); the rumble-event detector lives
inside `poll()`'s existing `INPUT.device === 'pad'` branch so it's automatically device-gated; the HUD
glyph legend falls back to the old plain-text label when `GLYPHS` is undefined, matching the codebase's
existing defensive-guard style.
