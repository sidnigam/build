    Create `js/sprites.js` as a `'use strict'` self-contained vanilla-JS global named `SPRITES` (mirror the CAMERA pattern in renderer.js — no module system, no import at module scope). Implement exactly:

    Fields: `ready: false`, `app: null`, `sheets: {}` (key → loaded spritesheet), `_missing: new Set()`.

    `async init(canvasEl)` — D-05 headless guard: at the TOP, `if (typeof navigator === 'undefined' || typeof document === 'undefined') return;` (RESEARCH Pitfall 3: smoke sandbox HAS document but NOT navigator, so guard on navigator).     `get(key)` — `return this.sheets[key];`

    `groupFramesByAnimation(frameNames)` — pure function (no Pixi, runs headless). Group frame names by their `{actor}_{state}` prefix (everything before the final `_<digits>.png`). Within each group, sort ascending by the trailing numeric index (parse the digits between the final `_` and `.png`). Return `{ [animName]: [frameName, ...] }` where animName is the `state` portion (last underscore-segment before the index). Use a regex like `/^(.*)_(\d+)\.png$/` to split prefix and index; the animation key is the segment after the actor, but for grouping use the full `{prefix}` minus actor — to keep it deterministic, key by the substring between the FIRST underscore and the index (i.e. for `player_idle_0.png` → key `idle`; for `tataka_phase2_idle_00.png` → key `phase2_idle`). Implement: strip `.png`, split on `_`, last token is the numeric index, first token is the actor, the join of middle tokens is the animation name. Concrete: `name.replace(/\.png$/,'').split('_')` → `[actor, ...mid, idx]`; animName = `mid.join('_')`; index = `Number(idx)`.
