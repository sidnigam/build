<interfaces>
**`PAD.familyFromId(id)`** (js/gamepad.js about L60):
- Vendor `054c` → 'ps', `045e` → 'xbox'.
- `/xbox|xinput|microsoft/` → 'xbox'.
- `/dualsense|dualshock|playstation|wireless controller/` → 'ps'.
- Anything else → 'generic'.
- `_parseVendorProduct` handles both the `vendor: 28de` form and the `28de-11ff-` form.
- `PAD.state.family` defaults to 'generic'. `GLYPHS.padToken` makes generic mirror xbox.

**`INPUT.device`** (js/game.js L9):
- Defaults to 'kbm'.
- gamepad.js sets it to 'pad' on pad input at about L355, and back to 'kbm' at about L309.
- `GLYPHS.signature()`/`refresh()` re-render on change, and toggle `body.pad-mode`.

**`window.chakraNative`** (preload): `{ ..., setFullscreen, getFullscreen }` through `ipcRenderer.sendSync`. There is a sync IPC pattern in main.js (`fullscreen:get`). `electron/util.js` exists from 06-01; it holds the pure helpers and has unit tests in test/electron-bridge.test.js. Window: `new BrowserWindow({ width: 1280, height: 720, ... webPreferences {contextIsolation, nodeIntegration:false, sandbox:true} })`. **Never** loosen webPreferences (06-CONTEXT D-03).

**Canvas text with dynamic sizes:**
- game.js about L1055: `` `bold ${t.size}px Georgia` `` (floating text)
- game.js about L1291 and L1314: `` `bold ${badgeSize - 3}px Georgia` ``
- glyphs.js L257: `` `bold ${size - 3}px Georgia` ``. With `drawTokens(ctx,x,y,tokens,size=14)` this gives 11px; a size-10 caller gives 7px.

Static canvas fonts of 10-11px exist, so grep `ctx.font =`. Smallest CSS sizes: 11px (`.card-rarity`, `.foot`, `.dlg-speaker`) and 11.5px (`#god-dialogue-hint`). Effective px = CSS px × the scale applied to the game container, and canvas px × (canvas.clientHeight / canvas.height) × the ctx transform scale. Check whether Pixi Text is used: `grep -n "PIXI.Text\|new Text(" js/*.js`.

**CDP pattern** (tools/browser-check.mjs):
- spawn Chrome with `--remote-debugging-port`
- `send(method, params)` / `evalJs(expr)` IIFE / `shot(name)` through `Page.captureScreenshot`

- `tools/art/god_panel_shots.mjs` and `tools/art/boss_shots.mjs` show how to force `UI.offerBoon(god)` and boss rooms, and they start their own `python3 -m http.server`
