```js
const ENEMY_TG = {
  MIN: { melee: 0.30, ranged: 0.30, status: 0.40, stun: 0.50, beam: 0.70, bite: 0.20 },
  violations: [], windLog: [], fireLog: [],
};
const ENEMY_AI = {
  CFG: {
    MELEE_R: 70, RANGED_BAND: [260, 380], SLOTS_MELEE: 8, SLOTS_RANGED: 10,
    REPICK: [0.5, 1.0], CUT_BIAS: 0.7,             // rad: melee slot angles rotate toward the player's heading
    TOKENS: { melee: 2, ranged: 2, heavy: 1, support: 1, bite: 4 },
    TOKEN_BIOME: [0, 1, 1, 2],                     // added to melee and ranged per biome index
    VIEW_ZOOM: 1.3, VIEW_MARGIN: 40, LONG_TELL_BONUS: 0.3,
    SEP_PUSH: 220, VAR: [1.0, 1.3],
  },
  holders: {}, slots: new Map(), pv: { x: 0, y: 0 }, _last: null,
  ...
};
```
Methods (all read GAME/CAMERA/DATA at call time):
- `reset()`: `holders = {}` (category → Set of enemies), `slots = new Map()`, `pv = {x: 0, y: 0}`, `_last = null`.
- `pool(cat)`: `CFG.TOKENS[cat] + ((cat === 'melee' || cat === 'ranged') ? (CFG.TOKEN_BIOME[GAME.biomeIdx] || 0) : 0) + (GAME.heat && GAME.heat.tokens ? GAME.heat.tokens : 0)` (the Heat hook stays inert until plan 09).
- `requestToken(e, cat)`: if the enemy already holds a token in `cat` return true; prune dead holders; if `set.size < pool(cat)` add and set `e.tokenCat = cat`, return true; else false. `releaseToken(e)`: remove from its category, `e.tokenCat = null`.
- `tick(dt)`: if no player return. Estimate player velocity: `pv` = exponential average (rate 8/s) of `(P - _last) / dt`. Prune dead token holders. For each living enemy with `e.def && e.def.role`: decrement `e.slotT`; when ≤ 0 re-pick the nearest free slot of its ring (melee ring for roles melee/heavy, ranged ring for ranged/support) and set `e.slotT = U.rand(REPICK[0], REPICK[1])`. Slot angle for index i of n: `i / n * TAU`; melee ring angles are rotated by `CUT_BIAS * clamp(|pv| / 300, 0, 1)` toward `atan2(pv.y, pv.x)` (bias the free-slot choice toward the heading: score = angular distance from the enemy's current bearing minus 0.8 × cos(slotAngle − heading)). Separation: O(n²) over living non-boss enemies; overlapping pairs push apart by `SEP_PUSH * dt` along the joining vector.
- `slotPoint(e)`: melee: `P + (MELEE_R + e.r) · (cos, sin)(slotAngle)`; ranged: `P + mid(RANGED_BAND) · (cos, sin)(slotAngle)`.
- `steer(e, dt, mul = 1)`: target = slotPoint(e) (fallback: P). Ranged roles: if `dist < band[0]` move directly away; if `> band[1]` move toward the slot point; otherwise strafe toward the slot point at 0.6 speed. Melee/heavy: move toward the slot point; within 30 px of it close in on P. Speed = `e.curSpeed() * mul`. No clamp here (Enemy.update clamps).
- `viewBand(P)` / `inViewBand(x, y, P)` exactly as in `<behavior>` (VW/VH from CAMERA or 1280/720).
- `windTime(kind, base)`: `Math.max(ENEMY_TG.MIN[kind] || 0.3, base) * U.rand(CFG.VAR[0], CFG.VAR[1])`.
