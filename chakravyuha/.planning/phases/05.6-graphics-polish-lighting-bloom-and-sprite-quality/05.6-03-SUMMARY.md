## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed `git_show_bytes()` path resolution for the worktree's nested project layout**
- **Found during:** Task 1, first `--legacy-check` run
- **Issue:** `rebuild_atlases.py`'s git-HEAD diff helper assumed `REPO_ROOT` was the git toplevel; in this worktree the git root is one level above the `chakravyuha/` project directory, so every `git show HEAD:<path>` call failed and every actor reported "no committed HEAD frame found".
- **Fix:** Resolve the path relative to `git rev-parse --show-toplevel` before calling `git show`.
- **Files modified:** `tools/art/rebuild_atlases.py`
- **Verification:** Re-ran `--legacy-check`; 12/13 actors immediately reproduced at diff 0.000.
- **Committed in:** `6cb97a4` (Task 1 commit)

**2. [Rule 1 - Bug] Fixed `sharpen_rgba()`'s nearest-opaque color-bleed (two compounding bugs)**
- **Found during:** Task 1, first `finish_sprite.py --sharpen` test
- **Issue:** `scipy.ndimage.distance_transform_edt(..., return_indices=True)` with `return_distances=False` returns a single `(2,H,W)` index array, not a tuple — the code's `_, indices = distance_transform_edt(...)` silently unpacked it wrong (iterating the array's first axis), and the resulting fancy-indexed array wasn't C-contiguous, which crashed `Image.fromarray()` with "not enough image data".
- **Fix:** Capture the full index array directly (no tuple-unpack) and wrap the fancy-indexed result in `np.ascontiguousarray()`.
- **Files modified:** `tools/art/finish_sprite.py`
- **Verification:** `--sharpen --outline N` now runs cleanly; visually confirmed no dark halos at sprite edges.
- **Committed in:** `6cb97a4` (Task 1 commit)

**3. [Rule 1 - Bug] Fixed `_gen/.gitignore` being clobbered by `recover_sources.py`'s first run**
- **Found during:** Task 1, first `recover_sources.py` run
- **Issue:** The script's gitignore-ensure helper unconditionally overwrote the committed `_gen/.gitignore` (which is `*\n!.gitignore\n`, so the gitignore file itself stays tracked) with a bare `*`, making the tracked gitignore file itself show as locally modified.
- **Fix:** Only write a fresh gitignore when the file is missing; otherwise leave the committed one untouched (just warn if it somehow lacks a bare `*` rule).
- **Files modified:** `tools/art/recover_sources.py`
- **Verification:** `git status --porcelain assets/sprites/_gen` is clean after every run.
- **Committed in:** `6cb97a4` (Task 1 commit)

**4. [Rule 1 - Bug] Tataka's outline tuned down from the table default (5px → 1px)**
- Covered in detail above under "Review Notes Per Actor" — a readability bug caught by the plan's own required review step, fixed within the plan's explicit tuning-loop allowance (3 rounds max; 1 round used).
- **Committed in:** `500ef95` (Task 3 commit)
