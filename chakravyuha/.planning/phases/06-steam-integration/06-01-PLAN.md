**main.js** (keep every existing handler and the `webPreferences` exactly as they are, per D-03):

- `const { createSteamBridge, resolveAppId, isValidApiName } = require('./steam')`.
- At module top level, **before** `app.whenReady`, build the bridge:
  ```js
  const steam = createSteamBridge({
    appId: resolveAppId({ isPackaged: app.isPackaged, env: process.env }),
    disabled: process.env.CHAKRA_NO_STEAM === '1',
    log: (m) => console.log('[steam]', m),
  });
  steam.enableOverlay();
  ```
  Skip `enableOverlay` when disabled.
- In `whenReady`, call `steam.init()` **before** `createWindow()`, so the renderer sees its final status at boot.
- **CHAKRA_DIAG (D-08).** If `process.env.CHAKRA_DIAG === '1'`, print `JSON.stringify({ userData: app.getPath('userData'), saves: savesDir(), steam: steam.status(), packaged: app.isPackaged })` to stdout. Do not create a window when `CHAKRA_DIAG` is set, unless `CHAKRA_STEAM_SELFTEST` is also set.
- **Dev self-test.** Only when `!app.isPackaged`, with `CHAKRA_STEAM_SELFTEST=<SpacewarApiName>`:
  - after `ready-to-show` plus `CHAKRA_STEAM_SELFTEST_DELAY` seconds (default 0), run `steam.selfTest(name, { clear: process.env.CHAKRA_STEAM_SELFTEST_CLEAR === '1' })` and print the JSON
  - with `CHAKRA_STEAM_SELFTEST_OVERLAY=Achievements|Friends`, call `steam.activateOverlay(...)` after the same delay
  - in DIAG mode with selftest, run it immediately after init, then quit
  - with `CHAKRA_STEAM_SELFTEST_READ=<name>` in DIAG mode, add `isUnlocked: steam.isUnlocked(name)` to the DIAG JSON. This is read-only and is used to prove persistence across restart.

  This lets 06-03 verify persistence across restart, and the toast and overlay, without devtools.
- IPC handlers. Mirror the store:* style. Each handler is wrapped in try/catch and validates its input with `isValidApiName` and integer checks:
  - `ipcMain.on('steam:status', e => e.returnValue = steam.status())`
  - `on('steam:unlock', (e, n) => steam.unlock(n))`
  - `on('steam:isUnlocked', e => returnValue)`
  - `on('steam:stat:set', ...)`
  - `on('steam:stat:get', ...)` (sync)
  - `on('steam:store')`
  - `on('steam:overlay:open', (e, d) => steam.activateOverlay(d))`
- On `before-quit`, call `steam.shutdown()` (clears intervals).
