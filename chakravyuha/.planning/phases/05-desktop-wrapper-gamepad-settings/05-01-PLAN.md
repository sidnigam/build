**js/storage.js — STORE (new global, no dependencies on other js/*.js files):**
```js
const STORE = {
  _mode: null,        // 'desktop' | 'browser' | 'headless' — set by init()
  _cache: {},          // per-key cache, all modes
  _memory: {},          // headless-only backing store

  resolveMode(hasChakraNative, hasLocalStorage) { /* pure: desktop > browser > headless */ },
  init() { /* sets this._mode via resolveMode(!!window.chakraNative, typeof localStorage !== 'undefined') */ },
  get(name, fallback) { /* returns parsed JSON or fallback; desktop mode lazily migrates from localStorage on first miss */ },
  set(name, value) { /* writes to cache + underlying store for the resolved mode */ },
  remove(name) { /* removes from cache + underlying store */ },
};
```
Call `STORE.init()` once, near the top of `js/storage.js` itself (top-level), so `_mode` is resolved before any other script's `load()`/`save()` methods run later (they only run after `DOMContentLoaded`, so exact script-tag position relative to other files does not matter — see 05-CONTEXT.md wave note).

**electron/preload.js — exposed to renderer as `window.chakraNative`:**
```js
window.chakraNative = {
  isDesktop: true,
  saveRead(name) /* string|null, SYNCHRONOUS via ipcRenderer.sendSync */,
  saveWrite(name, json) /* void, fire-and-forget via ipcRenderer.send */,
  setFullscreen(bool) /* void, fire-and-forget */,
  getFullscreen() /* boolean, SYNCHRONOUS via ipcRenderer.sendSync */,
  quit() /* void */,
};
```

**js/meta.js edit:** `load()` reads `STORE.get(this.KEY, null)` instead of `localStorage.getItem`; `save()` calls `STORE.set(this.KEY, {...})` instead of `localStorage.setItem`; `wipe()` calls `STORE.remove(this.KEY)` instead of `localStorage.removeItem`. No other behavior in `meta.js` changes.
