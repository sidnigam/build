Fields: `sx: 0, sy: 0, tx: 0, ty: 0, tz: 1, VW: 1280, VH: 720`,
`CFG: { FOLLOW_RATE: 7, LOOK_AIM: 0.2, LOOK_AIM_MAX: 110, LOOK_MOVE: 40, SNAP_DIST: 900, CULL_MARGIN: 48,
        IND_INSET: { l: 28, r: 28, t: 96, b: 64 }, IND_SECTORS: 16, IND_MAX: 8 }` (tag each `// tunable:`).

Methods (all pure unless noted; read GAME/DATA/INPUT at call time with `typeof` guards, D-09):
- `pad()` -> `(typeof DATA !== 'undefined' && DATA.ARENA && DATA.ARENA.pad) || {l:50,r:50,t:84,b:56}`.
- `worldRectFor(A, pad)` -> `{x:A.x-pad.l, y:A.y-pad.t, w:A.w+pad.l+pad.r, h:A.h+pad.t+pad.b}`.
- `anchor()` -> `{x: VW/2, y: (pad.t + VH - pad.b)/2}` (=640,374).
- `clampScroll(dx, dy, R)` -> per axis lo=R.x, hi=R.x+R.w-VW (y: R.y, R.y+R.h-VH); lo>hi ? (lo+hi)/2 : U-free clamp.
- `lookAhead(P, aimW, move)` -> `v = (aimW - P) * LOOK_AIM` clamped to length LOOK_AIM_MAX, plus `move * LOOK_MOVE` (move is a unit-or-zero vector {x,y}).
- `desiredScroll(P, aimW, move, R)` -> clampScroll(P.x + la.x - anchor.x, P.y + la.y - anchor.y, R).
- `xform(shx = 0, shy = 0)` -> uses `s = shakeScale()`, `z = this.zoom`, F=(fx,fy), S=(sx,sy), k=(kx*s+shx, ky*s+shy):
  `tz = z; tx = fx - z*fx - sx + kx; ty = fy - z*fy - sy + ky` (exact math in CONTEXT D-06). Returns {tx,ty,tz}; does not store.
- `_store(x)` stores tx/ty/tz (impure helper).
- `worldToScreen(wx, wy)` -> `{x: wx*tz + tx, y: wy*tz + ty}`; `screenToWorld(x, y)` -> `{x:(x-tx)/tz, y:(y-ty)/tz}` (use stored tx/ty/tz).
- `viewRect(margin = 0)` -> top-left = screenToWorld(0,0), size VW/tz x VH/tz, expanded by margin on all sides.
- `visible(x, y, r = 0, margin = CFG.CULL_MARGIN)` -> circle-AABB vs viewRect(margin) overlap; `visibleRect(x, y, w, h, margin)` likewise for rects.
- `edgePoint(wx, wy, inset = CFG.IND_INSET)` -> s = worldToScreen; if s inside [inset.l, VW-inset.r] x [inset.t, VH-inset.b] return null;
  else intersect the ray anchor->s with that inset rectangle (parametric: smallest t in (0,1] hitting any side) -> `{x, y, angle: atan2(s.y-a.y, s.x-a.x)}`.
- `clusterIndicators(items, opts = {})` -> items `[{x, y, kind: 'enemy'|'boss'|'door', color, sym}]` (world coords).
  For each item compute edgePoint; skip nulls. Doors: one arrow each (never clustered). Others: bucket by
  `Math.floor(((angle + PI) / TAU) * sectors) % sectors`; per bucket keep the item nearest the view center (world distance) as the representative,
  `count` = bucket size, `kind` = 'boss' if any boss in bucket. Order: doors, then boss buckets, then by representative distance ascending; truncate to `opts.max ?? CFG.IND_MAX` (doors never truncated). Return `[{x, y, angle, count, kind, color, sym}]`.
- `follow(dt)` (impure): if no GAME / no player / `GAME.state === 'hub'`: sx=sy=0, store xform(), return.
  Else R = worldRectFor(GAME.arena, pad()); aimW = INPUT.wx/wy if numbers else INPUT.mx/my; move = normalized INPUT.ax/ay if nonzero else
  `PAD.digitalMoveVector(INPUT.keys, INPUT.bindings)` when PAD defined, else zero; D = desiredScroll(...); if hypot(D-S) > SNAP_DIST snap, else
  `k = 1 - Math.exp(-FOLLOW_RATE * dt)`; S += (D - S) * k; then `_store(xform())`.
- `snap()` (impure): same as follow but S = D immediately (hub/no player -> 0,0).
