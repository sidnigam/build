  1. USB: connect with a data-capable USB-C cable, then press the PS button.
  2. Bluetooth pairing: with the controller off, hold Create + PS for ~3–5 s until the light bar flashes rapidly. macOS: System Settings → Bluetooth → "DualSense Wireless Controller" → Connect. Windows: Settings → Bluetooth & devices → Add device → Bluetooth → "Wireless Controller".
  3. Focus the game window and press any button — browsers only expose a controller after a button press.
  4. If Steam is running with PlayStation Configuration Support, Steam Input may present the pad as an Xbox controller (Xbox glyphs appear) — expected; quit Steam or disable it for the browser test.
  5. macOS: the PS button opens the system game overlay/Launchpad by default (System Settings → Game Controllers). The game never uses the PS button.
  6. Rumble may be unavailable for DualSense depending on OS/browser version — this screen reports it.
