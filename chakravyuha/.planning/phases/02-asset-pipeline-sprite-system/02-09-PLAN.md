HEADLESS SMOKE STUB CONSTRAINTS (test/smoke.js El class). These are critical, because ui.js runs headlessly in smoke:
- Elements have ONLY: id, children, style (a plain {} object), classList {add, remove, contains}, innerHTML, textContent, onclick, appendChild, addEventListener, getBoundingClientRect, getContext.
- There is NO `dataset`, NO `setAttribute`, NO `style.setProperty`, NO `querySelector` on elements. Using any of them throws and fails smoke.
- Safe patterns: `card.className = '...'`, `card.style.cssText = '--god:#ff8c42;--rarity:#5cb8ff'` (a plain property assignment works in the stub AND sets custom properties in Chromium), `card.style.borderColor = ...`, and innerHTML strings.
- Assigning cssText replaces the inline style. Set cssText FIRST and any individual style properties AFTER it.
