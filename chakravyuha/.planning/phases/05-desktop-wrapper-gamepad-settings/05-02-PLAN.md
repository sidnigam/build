    - `PAD.digitalMoveVector({}, INPUT_DEFAULT_BINDINGS)` → `{dx:0, dy:0}` (no keys held).
    - `PAD.digitalMoveVector({w:true}, INPUT_DEFAULT_BINDINGS)` → `{dx:0, dy:-1}`.
    - `PAD.digitalMoveVector({w:true, d:true}, INPUT_DEFAULT_BINDINGS)` → normalized diagonal, `Math.abs(dx-0.707..)<1e-3 && Math.abs(dy+0.707..)<1e-3`.
    - `PAD.digitalMoveVector` respects a custom bindings map (e.g. `{moveUp:['i']}` + `{i:true}` → `dy===-1`) — proves rebinding actually changes behavior.
    - `PAD.poll()` does not throw when `navigator` is undefined (headless guard) — this is the critical Nyquist-rule case since the smoke sandbox has no `navigator`.
  </behavior>
  <action>
    Create `js/gamepad.js` implementing the `PAD` interface above:
    - `applyDeadzone(x, y, dz)`: `const mag = Math.hypot(x, y); if (mag < dz) return { x: 0, y: 0, mag: 0 }; const scaled = Math.min(1, (mag - dz) / (1 - dz)); return { x: (x / mag) * scaled, y: (y / mag) * scaled, mag: scaled };`
    - `mapGamepad(gp)`: read `gp.axes[CFG.AXIS.LX/LY/RX/RY]` (default 0 if missing) and `gp.buttons[CFG.BTN.X] && gp.buttons[CFG.BTN.X].pressed` (default false if missing) for each named button. Purely reads the passed-in `gp`-shaped object — no `navigator` access inside this function (that's what makes it unit-testable with a plain fake object).
    - `digitalMoveVector(keys, bindings)`: `let dx=0,dy=0; const held=(list)=>list.some(k=>keys[k]); if (held(bindings.moveUp)) dy-=1; if (held(bindings.moveDown)) dy+=1; if (held(bindings.moveLeft)) dx-=1; if (held(bindings.moveRight)) dx+=1; const mag=Math.hypot(dx,dy); if (mag>0){dx/=mag;dy/=mag;} return {dx,dy};`
    - `poll()`: `if (typeof navigator === 'undefined' || !navigator.getGamepads) return;` then `const gps = navigator.getGamepads(); const gp = gps && gps[0]; if (!gp) return;`. Compute `mapGamepad(gp)`, apply deadzone to both sticks. If either stick's `mag > 0` or any button is true, `INPUT.device = 'pad'`. Set `INPUT.ax = left.x; INPUT.ay = left.y;`. If `right.mag > 0 && typeof GAME !== 'undefined' && GAME.player`: `const ang = Math.atan2(right.y, right.x); INPUT.mx = GAME.player.x + Math.cos(ang) * CFG.AIM_REACH; INPUT.my = GAME.player.y + Math.sin(ang) * CFG.AIM_REACH;`. `INPUT.lmb = m.buttons.RT || m.buttons.A;`.
