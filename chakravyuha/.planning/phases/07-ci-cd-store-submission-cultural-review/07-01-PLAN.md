This plan builds the CI/CD pipeline for QA-01. It works today with zero secrets and is ready for signing. Specifically:
- a test runner
- perf-tolerant smoke thresholds
- the packaging configs: the unsigned config stays as it is, and a signed overlay config is added
- the hardened-runtime entitlements
- the GitHub Actions matrix with steps that are skipped when their secrets are absent
- artifact verification
- an inert SteamPipe deploy path

Purpose: the packaging pipeline gets validated well before the user has the signing credentials, so failures at the signing stage are isolated later (07-RESEARCH pitfall). This plan implements 07-CONTEXT D-01 to D-04, D-06 to D-08 and D-17.
Output: `.github/workflows/build.yml` and its supporting tools and tests. The workflow lives at the repo root, which assumes the post-subtree-split layout.

  - `HAS_MAC_SIGNING` (CSC_LINK)
  - `HAS_NOTARY_API_KEY` (APPLE_API_KEY_P8)
  - `HAS_NOTARY_APPLE_ID` (APPLE_ID)
  - `HAS_WIN_PFX` (WIN_CSC_LINK)
  - `HAS_AZURE_SIGNING` (AZURE_CLIENT_SECRET)

Build steps:
1. Checkout, setup-node, `npm ci`.
2. **mac unsigned**, if `runner.os == 'macOS' && env.HAS_MAC_SIGNING != 'true'`: `npx electron-builder --mac --publish never`, with env `CSC_IDENTITY_AUTO_DISCOVERY: false`.
3. **mac signed**, if `HAS_MAC_SIGNING == 'true'`:
   - First, if `HAS_NOTARY_API_KEY`, write `secrets.APPLE_API_KEY_P8` to `$RUNNER_TEMP/AuthKey.p8` and export `APPLE_API_KEY=$RUNNER_TEMP/AuthKey.p8` through `$GITHUB_ENV`.
   - Then run `npx electron-builder --mac --publish never --config build/electron-builder.signed.cjs`, with env:
     - `CSC_LINK`, `CSC_KEY_PASSWORD`
     - `APPLE_API_KEY_ID`, `APPLE_API_ISSUER`
     - `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`
   - After that, run `xcrun stapler validate` on the dmg and `spctl -a -vvv -t install` on the .app.
4. **win unsigned**, if Windows and neither `HAS_WIN_PFX` nor `HAS_AZURE_SIGNING`: `npx electron-builder --win --publish never`.
5. **win signed**, otherwise: the signed config, with env `WIN_CSC_LINK`, `WIN_CSC_KEY_PASSWORD`, `AZURE_TENANT_ID`, `AZURE_CLIENT_ID`, `AZURE_CLIENT_SECRET`, plus `vars.AZURE_SIGN_ENDPOINT`/`ACCOUNT`/`PROFILE`. Then `Get-AuthenticodeSignature dist/*.exe` (pwsh), which fails unless the status is Valid.
6. `node tools/ci/verify-dist.js --os ${{ runner.os }}`.
7. `actions/upload-artifact@v4` with:
   - `name: chakravyuha-${{ runner.os }}-${{ github.ref_name }}`
   - mac `path`: `dist/*.dmg` and `dist/mac*/Chakravyuha.app/**`
   - win `path`: `dist/*.exe` and `dist/win-unpacked/**`
   - `retention-days: 14`
   - `if-no-files-found: error`

Use bash shell for the steps, except the pwsh signature check. Before you finalize the env var names, confirm the notarize ones against the installed electron-builder 26 source (`app-builder-lib/out/macPackager.js` / `notarize`) (D-06).
