- Subject entry fields (prompts.json `env_subjects.{biome}.{key}`): template, size?, subject, palette, base_seed, role, ground_safe, negative_extra?, and manifest seeds worldH?, zones?, light?, low?, hazard?, skinFor?. - All python via `~/ComfyUI/venv/bin/python`.
</interfaces>

Review protocol for each biome (both tasks):
1. Write all subject entries. seeds: naraka 61000+, patala 62000+, spaced by 10 per subject (61000, 61010, …) so attempts 0-4 never collide.
2. Run `gen_batch --next-pending BIOME` in the background and poll the log.
3. Raw pass: one review_grid of all raws (≤ 16 per grid; split into 2 grids if more). Apply the README checklist (a)-(j) plus the phase rules:
   - tiles: top-down, no focal point, no radial composition, no walls/horizon.
   - wallface: a continuous horizontal wall with a clear band to crop.
   - props/columns/gates: a single isolated object on the plain background, whole object in frame, 3/4 view, no figures/faces/deities.
   - decals: flat marks on flat grey.
   - cultural (D-09): no deity/idol/face/yantra/Om/swastika/trishula/lotus/halo anywhere; nothing sacred on ground assets; no gore/bones/skulls/corpses.
4. Mark `accepted_attempt`, or add `rejected[seed] = reason` and re-run `--next-pending`. Change the prompt text (not only the seed) after 2 composition failures of the same kind (02-08/02-11 lesson). Follow the D-15 budget.
5. `env_build BIOME --check`, then `env_build BIOME`.
6. Finished pass: one grid of tiles/strips with `--repeat` (seams) and one grid of cutouts on `--bg checker` (clean alpha, no halo, readable silhouette). Fix by adjusting `crop` or grading, or by regenerating, then rebuild.
7. Fill `self_review` + `cultural_check` for every accepted subject (env_build refuses empty cultural_check). Set `ground_safe: true` only for ground roles that passed (j).
